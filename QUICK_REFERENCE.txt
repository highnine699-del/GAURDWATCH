INSTALLATION
────────────────────────────────────────────────────────────────────────────────
1. Double-click setup.bat
   OR manually run:
   pip install mss Pillow pyperclip pynput opencv-python pywin32 flask watchdog


RUNNING GUARDWATCH
────────────────────────────────────────────────────────────────────────────────

Start Monitoring with Web Dashboard (recommended):
  python guardwatch.py
  → Dashboard opens at http://localhost:5555

Silent Mode (no window, runs in background):
  pythonw guardwatch.py
  → Dashboard still available at http://localhost:5555

View Evidence from Past Sessions:
  python guardwatch.py --report

Delete All Evidence:
  python guardwatch.py --clear


WHAT GETS MONITORED
────────────────────────────────────────────────────────────────────────────────
✓  Webcam snapshot on wake (WHO sat at the PC)
✓  Every mouse click with annotated screenshot (WHAT they did)
✓  All keystrokes typed (passwords, searches, messages)
✓  Everything copied to clipboard (sensitive data)
✓  Which apps were in focus (programs opened)
✓  Browser history before/after (websites visited)
✓  Exact timestamps of idle/wake events (WHEN they used it)
✓  Failed login attempts (how they got in)
✓  USB devices inserted (file theft detection)
✓  Random timed screenshots (context of activity)
✓  FILE ACTIVITY MONITORING (NEW) — tracks file changes + suspicious patterns

SETTING UP AUTO-START (RUNS ON EVERY BOOT)
────────────────────────────────────────────────────────────────────────────────
Windows Startup Folder (easiest):
  1. Press Win+R → type: shell:startup → Enter
  2. Create a text file called guardwatch.bat:
     @echo off
     pythonw "C:\full\path\to\guardwatch.py"
  3. Save. Done — runs automatically on boot.

Task Scheduler (more reliable):
  1. Win+R → taskschd.msc → Enter
  2. Create Basic Task...
     - Name: GuardWatch
     - Trigger: At startup
     - Action: Start program
     - Program: pythonw.exe
     - Arguments: "C:\path\to\guardwatch.py"
  3. Check: Run with highest privileges
  4. Finish


STOPPING & EXITING
────────────────────────────────────────────────────────────────────────────────
While GuardWatch is running:
  Press Ctrl+C to stop cleanly

Important: Wait 2–3 seconds after Ctrl+C for HTML report to generate.
Do NOT force-kill (Task Manager) or evidence may be lost.


INTERPRETING EVENTS.JSON
────────────────────────────────────────────────────────────────────────────────
HIGH-priority events are the smoking gun:

⚠️  WAKE_FROM_IDLE
    PC woke from idle (someone started using it while you were asleep)

⚠️  WEBCAM_PHOTO
    Captured photo of whoever just sat down

⚠️  USB_INSERTED
    Someone plugged in a flash drive (trying to steal files?)

⚠️  FAILED_LOGINS
    Multiple wrong password attempts (they were guessing passwords)

⚠️  FILE_CREATED (NEW in v3.0)
    Suspicious file created (.exe, .bat, .ps1, etc.)

TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────

Q: No webcam photos captured?
A: Make sure your camera works in the Camera app first. If no camera is 
   available, GuardWatch logs a WEBCAM_SKIP event but continues monitoring
   other channels.

Q: "wevtutil access denied" error?
A: Run Command Prompt as Administrator. The failed login counter needs
   admin privileges to read Windows Security logs.

Q: Evidence folder missing?
A: It's hidden in AppData. Press Win+R and paste:
   %APPDATA%\Microsoft\CLR\gw_evidence
   (It will be created automatically on first run)

Q: Nothing recorded after I stopped?
A: Make sure you pressed Ctrl+C cleanly (not force-killed). Wait a few
   seconds for the HTML report to generate.
